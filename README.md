# Stone Paper Scissor Game (Turbo C Graphics)

A graphical Rock Paper Scissor game developed in C using Turbo C++ Graphics Library (graphics.h).

## Features

- Graphical interface using graphics.h
- Rock, Paper and Scissor animations
- Random computer moves
- Live score board
- Final score display

## Language

C

## Compiler

Turbo C++

## Graphics Library

graphics.h

## How to Run

1. Open Turbo C++
2. Open main.c
3. Make sure BGI path is:

C:\Turboc3\BGI

4. Compile (Alt + F9)

5. Run (Ctrl + F9)
